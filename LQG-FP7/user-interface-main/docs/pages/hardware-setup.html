Hardware Setup

For setting up the Red Pitaya (RP), you need to have a working console and SFTP access to the device. For Windows, we recommend WinSCP and Putty.

Python server

First, a few prerequisite packages must be installed on the Red Pitaya for the server to work:

  • python3-yaml
  • python3-bitarray
  • python3-numpy
  • python3-flask

They are also documented in the docs of ipcoreconfig. Install them using apt-get install python3-yaml python3-bitarray python3-numpy python3-flask. Note the RP needs internet to install the packages this way.

Copy over the coreconfig directory (entire directory + subdirectories) to some directory on the RP (root, for example). Copy the binary of the bitstream (e.g. lqg_fp7_v1.2.1.bin) into the lib lib/firmware directory. Also, always copy over the up-to-date version of ip_description.yaml to the RP. Then, configure the RP with the correct bitstream, for example:

echo "lqg_fp7_v1.2.1.bin" > /sys/class/fpga_manager/fpga0/firmware

Then run the server using:

coreconfig/server.py ip_description.yaml

assuming the current working directory is the parent directory of coreconfig and also contains the ip_description.yaml file. The console will display logs of incoming HTTP requests, but you can safely ignore it and now work purely with the GUI. To shut the server down, simply press Ctrl+C while the cursor is active in the console.
